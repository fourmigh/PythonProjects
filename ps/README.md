# PS Studio

桌面版「豆包风」P 图工具：打开图片，输入一句中文指令，生成修改后的图片。支持多轮修改、画笔/矩形选区局部编辑、抠图换背景、消除物体、批量处理和历史版本。

- 界面：PySide6 桌面应用
- AI 改图：硅基流动 `Qwen/Qwen-Image-Edit-2509`（阿里通义千问开源模型）
- 本地能力：rembg 抠图、OpenCV 修补
- 可选提示词优化：智谱免费文本模型

## 功能

- 自然语言改图：换背景、改衣服颜色、加/删物体、改风格、改图中文字等
- 剪贴板粘贴：微信/QQ/截图工具复制图片后按 Ctrl+V 直接载入
- 多轮连续修改：每次基于当前结果继续改
- 局部编辑：画笔或矩形选中区域，红色高亮提示模型；默认只把选区贴回，未选中区域像素不变
- 多候选：一次生成 1–4 张，缩略图挑选
- 抠图换背景：rembg 抠出主体，合成纯色或图片背景
- 消除物体：AI 消除选区；失败可改用本地 OpenCV 修补
- 批量处理：多张图使用同一指令，顺序执行
- 历史版本：每次结果独立保存，可回退、对比、导出

## 环境要求

- Windows（已在 Windows 10/11 测试）
- Python 3.11+（本项目在 Python 3.14 下开发）
- 能访问 `api.siliconflow.cn`

## 安装

```powershell
cd F:\Github\PythonProjects\ps
python -m pip install -r requirements.txt
```

抠图功能需要额外安装 rembg（首次运行会自动下载约 176MB 的 u2net 模型）：

```powershell
python -m pip install rembg onnxruntime
```

如果暂时不需要抠图，可以先跳过 rembg。

## 获取 API Key

1. 打开 https://cloud.siliconflow.cn 注册（手机号），完成实名认证。
2. 国内站新用户会赠送 ¥14 体验金，约可生成 46 张图。
3. 在控制台「API 密钥」页面创建 Key。
4. 可选：在 https://open.bigmodel.cn 创建智谱 Key，用于发送前优化提示词（免费模型）。

## 配置

每次启动程序都会自动弹出设置窗口，填入：

- 硅基流动 API Key
- 输出目录（默认 `ps/outputs`）
- 模型（默认 `Qwen/Qwen-Image-Edit-2509`）

API Key 只保存在本次运行的内存中，不会写入磁盘或配置文件；关闭程序后需要重新输入。智谱 Key 同理。设置窗口中的「清空 Key 输入」可以清空输入框，点「保存」后才会从本次运行中移除。

## 使用说明

### 全图修改

1. 打开或拖入图片。
2. 在右侧输入指令，例如：
   - `把背景换成海边，保持人物姿势和衣服不变`
   - `把外套改成米白色`
   - `删除画面左侧的路人`
3. 按 Ctrl+Enter 或点击「发送」。
4. 在「候选结果」里挑选满意的一张。

### 从微信/QQ/截图工具粘贴

1. 在微信、QQ、浏览器或截图工具中复制图片。
2. 回到 PS Studio，按 Ctrl+V，或点击左侧工具栏「粘贴」。
3. 如果当前已有图片，会先确认是否替换；之前的结果仍保存在 `outputs` 目录。
4. 状态栏出现「剪贴板中有图片，按 Ctrl+V 粘贴」时，说明可以直接粘贴。

### 局部修改

1. 点击左侧「画笔」或「矩形」。
2. 在图片上涂抹或框选要修改的区域，选中区域显示为红色半透明。
3. 输入指令，例如 `把这块区域换成木地板`。
4. 发送。

默认开启「局部编辑时只贴回选区」：生成结果只替换选区，其他区域保持原图像素不变，可显著减少整图漂移。可在设置中关闭。

### 消除物体

1. 涂抹要移除的物体或人物。
2. 点击左侧「AI 消除选区」。
3. 如果 AI 效果不好，点击「本地修补选区」使用 OpenCV 快速填补。

### 抠图换背景

1. 打开图片。
2. 点击「抠图换背景」。
3. 选择白色、纯色或图片背景。
4. 生成结果会作为新版本保存。

### 批量处理

菜单「文件 → 批量处理」：添加多张图片，填写统一指令，选择输出目录后开始。批量任务逐张执行，失败不计费。

### 历史与对比

- 每次生成都会保存到 `outputs/<时间戳>/`，包含原图、候选图、mask 和 `history.json`。
- 「上一版」回退到上一轮结果。
- 「原图对比」并排查看原图和当前结果。

## 常见问题

**微信复制图片后 Ctrl+V 没反应？**

个别版本可能只提供私有剪贴板格式，Qt 读不到。可以改用 Windows 截图工具（Win+Shift+S）复制，或先把图片另存为文件再打开。

**为什么每次启动都要输入 API Key？**

Key 只保存在本次运行的内存中，不写入磁盘、配置文件或系统凭据管理器。这样关闭程序后 Key 就不会留在本机。程序运行期间只需输入一次，之后可反复使用。

**提示 API Key 无效（401/403）**

检查 Key 是否复制完整、是否已实名、是否与接口地址匹配。

**提示余额不足（402）**

到硅基流动控制台充值。免费额度用完后按张计费。

**提示请求被拒绝（400/422）**

可能触发了内容审核，换一张图或调整指令。

**提示服务繁忙（429/503/504）**

程序会自动重试；仍失败时稍后再试。

**抠图提示未安装 rembg**

```powershell
python -m pip install rembg onnxruntime
```

**首次抠图很慢**

正在下载 u2net 模型，约 176MB，只需下载一次。程序会依次尝试 gh-proxy、ghproxy 镜像和 GitHub 官方地址。如果全部失败，可按提示手动下载 `u2net.onnx` 到：

```
C:\Users\<用户名>\.rembg\models\u2net\u2net.onnx
```

**生成结果和原图人物差别大**

- 使用画笔/矩形限定修改区域，并保持「只贴回选区」开启。
- 指令里明确写「保持人物身份、姿态、服装、光线不变」。
- 增加候选数量，多试几次或更换 seed。
