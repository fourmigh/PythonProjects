# SubCap — 视频中文字幕自动提取工具

自动从视频文件中提取中文字幕，截取最佳画面帧，输出结构化的 Excel 报表。基于 RapidOCR (PP-OCRv4) 实现高精度中文识别，无需 GPU、无需 Tesseract、无需 PaddlePaddle。

## 功能特性

- **自动字幕提取** — 逐帧扫描视频 → OCR 识别字幕 ROI → 合并相同字幕 → 保存最佳截图
- **高精度中文 OCR** — 基于 RapidOCR (ONNX Runtime)，使用 PP-OCRv4 中文识别模型，准确率 > 95%
- **双层广告过滤**
  - 字幕文本层：检测广告词特征（如"邀您观看精彩剧集"），按字频+比例过滤
  - 画面水印层：检测画面右下角水印区域中的"广告"等标记，跳过含广告水印的帧
- **智能去重** — 基于文本相似度 (SequenceMatcher) 合并连续相同字幕，避免重复截图
- **最佳帧选取** — 多维度画面质量评分：清晰度 + 人脸检测质量 + 构图 + 亮度，满分 100
- **可视化 ROI 编辑** — 鼠标拖拽调整字幕/水印识别区域，实时帧预览，即时保存
- **Excel 输出** — 字幕序号、时间轴、台词、截图文件名、质量分、截图预览内嵌
- **视频下载** — 内置 yt-dlp 下载器，支持流媒体平台

## 系统要求

- **Python** >= 3.10（已测试至 3.14）
- **操作系统**：Windows / Linux / WSL
- **硬件**：CPU 即可，无需 GPU
- **无需安装**：Tesseract、PaddlePaddle、PyTorch

## 快速开始

### 1. 安装依赖

自动安装（推荐） — 直接运行脚本，缺少的包会自动 pip 安装：

```bash
python subcap.py
```

手动安装：

```bash
pip install opencv-python rapidocr-onnxruntime openpyxl numpy
```

### 2. 准备视频

将视频文件放入 `videos/` 目录，支持格式：

| 格式 | 说明 |
|------|------|
| `.mp4` | 主流通用格式 |
| `.mkv` | 高清封装格式 |
| `.avi` `.mov` `.flv` `.webm` `.wmv` | 其他常见格式 |

或使用下载工具：

```bash
python download.py https://example.com/video
```

### 3. 调整识别区域（可选但推荐）

不同视频的字幕位置可能不同，首次处理建议先用编辑器确认 ROI：

```bash
python editor.py videos/01.mp4
```

**编辑器快捷键：**

| 操作 | 说明 |
|------|------|
| 鼠标拖拽手柄 | 调整红色（字幕）/ 蓝色（水印）框 |
| `[frame]` 滑块 | 跳转时间线 |
| `[+]` / `[-]` | 前后逐帧 |
| `[[]` / `]]]` | 前后跳 10 帧 |
| `[s]` | 保存 `roi_config.json` |
| `[q]` | 退出 |

### 4. 运行主程序

```bash
python subcap.py
```

自动处理 `videos/` 目录下所有视频文件，输出到同名子目录和 xlsx 文件。

## 输出说明

`videos/{视频名}_screenshots/{序号}_{台词前50字}.jpg`

## 配置与调优

### ROI 配置文件

`roi_config.json` 存储在视频文件同目录，通过 `editor.py` 生成，内容为百分比坐标：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `subtitle_x1` | 0.0 | 字幕区域左边界（% of width） |
| `subtitle_x2` | 1.0 | 字幕区域右边界 |
| `subtitle_y1` | 0.65 | 字幕区域上边界（% of height） |
| `subtitle_y2` | 0.95 | 字幕区域下边界 |
| `wm_x1` | 0.65 | 水印区域左边界 |
| `wm_y1` | 0.88 | 水印区域上边界 |
| `wm_x2` | 1.0 | 水印区域右边界 |
| `wm_y2` | 1.0 | 水印区域下边界 |

### 脚本参数调优

`subcap.py` 主函数中可调参数（第 415-422 行）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `similarity_threshold` | 0.7 | 文本相似度阈值，越低合并越激进 |
| `min_text_length` | 4 | 最小保留文本长度（过滤短文本/噪声） |
| `skip_frames` | 2 | 跳帧间隔（每 N+1 帧处理一帧） |

### 广告词表

- **字幕广告词**：`_AD_CHARS`（第 65 行），适用于出现在字幕区域内的广告文本
- **水印广告词**：`_WATERMARK_AD_CHARS`（第 92 行），适用于画面角落的水印标记

按识别结果添加对应字符即可扩展。

## 技术原理

### OCR 引擎

使用 **RapidOCR**（`rapidocr-onnxruntime`）替代传统 Tesseract：

- 模型：PP-OCRv4 中文识别模型（与 PaddleOCR 相同）
- 推理后端：ONNX Runtime（无需 PaddlePaddle 框架）
- 模式：`use_text_det=False` — 跳过文本检测，直接识别已裁剪的 ROI 区域
- 速度：单帧 ~20-50ms（CPU），远快于 Tesseract 的多语言模式

### 人脸检测

使用 **OpenCV FaceDetectorYN**（YuNet ONNX 模型）：

- 模型自动从 OpenCV Zoo 下载（~330KB）
- 用于画面质量评分中的"人脸质量"维度
- 评分维度：人脸数量、居中程度、大小适配、眼部清晰度

### 帧质量评分系统

```
总分 100 = 清晰度(30) + 人脸质量(35) + 构图(20) + 亮度(15)
```

- **清晰度**：拉普拉斯方差，越高越清晰
- **人脸质量**：人脸数量、位置（居中加分）、大小（占画面 1%-15% 加分）、眼部清晰度
- **构图**：画面中央区域纹理复杂度
- **亮度**：画面平均亮度在合理范围（80-200）内得分

### 广告过滤逻辑

1. 字幕 ROI → OCR → `_is_subtitle_ad()` 检查文本特征
   - 中文字符 < 4 → 丢弃（短文本噪声）
   - 英文字符 > 中文 × 2 → 丢弃（非中文内容）
   - 广告词命中 ≥ 3 且占比 ≥ 50% → 丢弃
2. 水印 ROI → OCR → `_has_ad_watermark()` 检查广告标记
   - 在画面右下角水印区域 OCR
   - 检测到"广"、"告"等关键词 → 丢弃该帧

### 字幕去重

连续帧的 OCR 结果通过 `SequenceMatcher` 比较清洗后的文本（去除非字母/汉字字符）：

- 相似度 > 阈值 → 属于同一字幕片段，累积帧
- 相似度 ≤ 阈值 → 新字幕，从累积帧中选最佳帧保存

## 常见问题

### 无字幕被提取出来

- 确认视频文件路径正确，放入了 `videos/` 目录
- 运行 `editor.py` 检查字幕 ROI 是否覆盖了字幕区域（默认 y1=0.65, y2=0.95）
- 某些视频字幕在画面顶部或侧面，需调节 ROI

### 截图质量不理想

- 人脸评分可能偏低：确认 `face_detection_yunet_2023mar.onnx` 已下载
- 画质分偏低：检查清晰度评分，视频本身模糊会影响结果

### 广告过滤不干净

- 在 `_AD_CHARS`（字幕文本）或 `_WATERMARK_AD_CHARS`（画面水印）中添加识别到的广告字符
- 如果广告出现在非默认 ROI 位置，用 `editor.py` 调整水印检测区域

### 速度太慢

- 增大 `skip_frames`（如改为 5，每 6 帧处理一帧）
- `similarity_threshold` 设大可以减少保存时的质量评分计算

### RaptorOCR 模型下载失败

首次运行会自动下载模型，如网络不稳定可手动下载：
- 模型位于 `~/.rapidocr/` 或 `~/.paddlex/` 目录
- 设置 `PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK=True` 跳过下载检查
